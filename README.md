# SmartLibrary

SmartLibrary is a library management system built with ASP.NET Core. It provides a simple web application for managing books, publications, borrowing records, and user-facing library pages.

## Features

- Manage books and publications
- Track borrowing and return workflows
- Support librarian and student-related views
- Built with ASP.NET Core MVC and Entity Framework Core

## Project Structure

- LMSystem/ - Main web application
- LMSystem.Tests/ - Test project
- LMSystem.slnx - Solution file

## Getting Started

1. Install the .NET SDK (version compatible with the project).
2. Restore dependencies:
   ```bash
   dotnet restore
   ```
3. Run the application:
   ```bash
   dotnet run --project LMSystem/LMSystem.csproj
   ```
4. Open the local URL shown in the terminal.
